## Этап 3. Виртуальная файловая система

### Общее описание

На третьем этапе подключена виртуальная файловая система:
- источником VFS служит каталог на диске, он указывается в `--vfs`;
- при запуске каталог целиком читается в память, все команды работают
  только с копией в памяти, файлы на диске не меняются;
- ошибки загрузки: путь не найден и неверный формат
  (указан файл, а не каталог);
- служебная команда `vfs-info` показывает имя VFS и хеш SHA-256;
- созданы три тестовые VFS и скрипты для их проверки.

### Описание классов и методов

- `VfsNode` описывает файл или каталог: имя, содержимое и потомков.
- `Vfs` хранит корень дерева, имя VFS и считает хеш методом `getHash`.
- `VfsLoader` методом `load` читает каталог с диска в память.
- `VfsHasher` считает SHA-256 по структуре и содержимому дерева.
  Узлы обходятся в порядке сортировки имён, поэтому хеш не зависит
  от порядка файлов на диске.
- `VfsException` описывает ошибку загрузки VFS.
- `ShellWindow` загружает VFS при запуске и сообщает об ошибке.
- `Shell` получил команду `vfs-info`.

### Описание настроек

Параметр `--vfs` теперь загружает VFS. Имя VFS совпадает с именем каталога.
При ошибке загрузки эмулятор сообщает о ней и работает без VFS.

### Описание команд для сборки и запуска тестов

    make test

Тестовые VFS лежат в папке `vfs/`:
- `minimal` — один файл;
- `several` — несколько файлов, в том числе с пробелом в имени;
- `deep` — вложенность в 4 уровня.

Скрипты для проверки:

    bash scripts/test_vfs_minimal.sh      минимальная VFS
    bash scripts/test_vfs_several.sh      несколько файлов
    bash scripts/test_vfs_deep.sh         вложенные каталоги
    bash scripts/test_vfs_not_found.sh    VFS не найдена
    bash scripts/test_vfs_bad_format.sh   вместо каталога файл
    bash scripts/test_all_commands.sh     все команды всех этапов

### Примеры использования

    vfs$ vfs-info
    vfs-name=deep
    vfs-sha256=cca8a71a6db52e30f1af571fc74dced3503965e4d1c18c52509acfaaa1908dc5

Каталог не найден:

    vfs error: path not found: vfs/no_such_dir
    vfs$ vfs-info
    vfs-info: no VFS loaded

Вместо каталога указан файл:

    vfs error: invalid format, not a directory: vfs/minimal/hello.txt
