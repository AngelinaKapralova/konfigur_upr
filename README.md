# konfigur_upr
Репозиторий для выполнения практических работ по конфигурационному управлению
## Этап 1. REPL

### Общее описание

На первом этапе сделан минимальный прототип с графическим окном:
- окно с заголовком `VFS - Shell Emulator`: сверху вывод, снизу строка ввода;
- разбор аргументов в кавычках;
- сообщения об ошибках: неизвестная команда, неверные аргументы,
  незакрытая кавычка;
- команды-заглушки `ls` и `cd`, которые выводят своё имя и аргументы;
- команда `exit`, закрывающая окно.

### Описание классов и методов

- `Main` запускает окно эмулятора методом `main`.
- `ShellWindow` строит окно (поле вывода и строка ввода) и по нажатию Enter
  передаёт строку в `Shell` методом `handleInput`.
- `Shell` выполняет команду методом `execute` и сообщает, что пользователь
  ввёл `exit`.
- `CommandParser` делит строку на слова методом `parse`. Текст в двойных
  кавычках считается одним аргументом.
- `CommandException` описывает ошибку для пользователя. Её сообщение
  печатается в окне.

### Описание настроек

Настроек нет. Всё работает без параметров.

### Описание команд для сборки и запуска тестов

    make run
    make test

### Примеры использования

    vfs$ ls -l /home
    ls -l /home
    vfs$ cd "My Documents"
    cd My Documents
    vfs$ foo
    foo: command not found
    vfs$ cd a b
    cd: too many arguments
    vfs$ ls "abc
    parse error: unclosed quote
    vfs$ exit now
    exit: too many arguments
    vfs$ exit

После `exit` окно закрывается.
